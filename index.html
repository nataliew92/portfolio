still life project

A fictional e-commerce site for a still life item.

Role
Student Project at Edge Hill University
Stack
HTML · CSS · JavaScript · model-viewer for 3D
Year
2026

// the brief

The task was to find any item I had at home and design a single-page website to sell it. It had to be original in both visuals and content without resembling the actual product's website, functioning as a believable but fictional e-commerce shop.

I chose a perfume bottle I already owned. The challenge was that the real high-fashion brand markets it as a luxury product with clean white backgrounds, minimalist typography, and an editorial magazine feel. I deliberately wanted to reinterpret it through a different lens: a fairytale, romantic aesthetic that leaned into the florals the fragrance is built on. The intention was to make the same product feel like something else entirely and tell a different story.

// the design

This was the part of the project I spent the most time on. The brief was technical at heart, but I treated it as an opportunity to lean fully into visual direction, building a complete world for a fictional brand rather than just dressing up a page.

My references:

  • venusetfleur.com
  • Selkie
  • Sandy Liang
  • Pre-Raphaelite paintings
  • English botanical gardens
  • Sistine Chapel
  • Vatican Museum

These pulled the project away from the original brand's modern, high-fashion identity and into something softer, older, and more whimsical.

The starting point was nothing more than a photo taken on my phone of the perfume bottle sat on a cardboard box in my living room. I upscaled it using AI, then used generative AI [Nano Banana] prompting to develop every other visual on the site - using only that upscaled photo and my own written prompts as input. No stock imagery, no asset libraries. This part of the project taught me more about visual communication than the technical work did, and built up a real sense of how to use AI tools as a creative collaborator.

// the build

  • Built a fully responsive layout with CSS Grid and a mobile-first approach, supporting modern browsers down to IE8 with graceful fallbacks.
  • Integrated Google's <model-viewer> web component to display an interactive 3D model of the perfume bottle, complete with AR support.
  • Built an accessible custom accordion for the fragrance notes section, with each note having its own accent colour exposed via CSS custom properties.
  • Wrote semantic HTML5 throughout using appropriate landmarks, aria-labelledby, aria-expanded, and a prefers-reduced-motion media query disabling animations for users who request it.
  • Made deliberate trade-offs during development. A parallax hero effect was removed mid-build after I diagnosed it was causing rendering jitter due to overlapping stacking contexts, choosing the more stable solution over the more impressive one.

// reflection and work in progress

If I were to revisit this project I'd plan the design system properly upfront rather than refactoring colour and spacing tokens mid-build.

The 3D bottle was generated using Meshy, a free AI modelling tool. The quality reflects that. For a real production site, I'd commission a proper 3D artist or model it manually in Blender to get crisper geometry and better textures. It was the right choice for a student project where the goal was integration and interactivity rather than asset fidelity.

I'd also explore view-timeline for scroll-driven animations now that I better understand the compositing implications. The biggest takeaway was learning to use AI as a real creative tool rather than a shortcut, and trusting research, inspiration and design instinct enough to commit to a strong aesthetic direction.

The page is a work in progress. I plan to keep iterating on it by refining the model viewer on mobile, exploring more motion, and running proper accessibility audits to inform the next round of improvements.

doggie walks

A multi-page website built from a client requirements brief.

Role
Student Project at Edge Hill University
Stack
HTML · CSS · JavaScript
Year
2026

// the brief

This project simulated a real client relationship. I was given a customer requirements document from a fictional client [Lori Hanson, founder of Doggie Walks] and tasked with interpreting it into a fully working multi-page website. The client provided page content, a logo, a set of images, reference websites they liked, and a list of requirements including pastel colours, paw print patterns, a contact form, a gallery, and contact details on every page.

The overall brief framed this as an exercise in what most developers experience on a day-to-day basis: translating a client's vision into a live product, filling in the gaps where the brief was light, and making design decisions the client hadn't specified.

// the design

The client's brief was content-heavy but light on design specifics. They knew they wanted pastel blue, clean fonts, and an emphasis on imagery. Everything else was my interpretation. I referenced the sites they provided and used them as a starting point for layout and navigation patterns, then made my own design decisions from there.

My references:

  • borrowmydoggy.com
  • dogwalkingmonton.co.uk
  • dogwalkingmanchester.com

The palette built around soft pastel blue with warm white and muted tones throughout. Typography pairs Merriweather Sans for display headings with Inter for body text. The client specifically requested paw print patterns in the background, which I implemented as a repeating CSS background image across key sections. I created this background using a Nano Banana text prompt and edited it further using Canva.

// the build

  • Built as a multi-page site with consistent navigation, a shared header and footer, and contact details present on every page as the client requested.
  • Services page used CSS 3D flip cards — hover on desktop, tap on mobile — to present the three service tiers with pricing on the front and full details on the back.
  • Implemented a responsive hamburger menu in vanilla JavaScript with aria-expanded updating to reflect state for screen readers.
  • Built a fully responsive layout throughout using CSS Grid — single column on mobile, scaling to multi-column at tablet and desktop breakpoints across every page.
  • A scrolling promotional banner for the new customer offer using CSS animation, giving the page energy without being intrusive.
  • Contact form built with semantic <fieldset> and <legend> grouping, proper label associations, and all three branch addresses as specified by the client.

// reflection

The biggest challenge was filling the gaps the client didn't specify. The brief told me what they wanted but not how. Layout, hierarchy, spacing, and feature decisions were all mine. This gave me a real sense of what client work actually feels like, and how much of a developer's job is interpretation rather than following instructions.

If I were to revisit it I'd separate the CSS into page-specific files earlier as the single stylesheet became unwieldy by the end. I'd also revisit the gallery page, which ended up more static than I'd have liked.

// where I'm coming from

I'm a graduate UX designer with a foundation in web design, development and analytics — a combination that lets me sit comfortably between research, design and engineering. I've spent my degree running full UCD projects from initial discovery and data gathering through to design, prototyping and usability testing, including a research-driven redesign of my university's student platform and a generous-interface map prototype built around the Victoria & Albert Museum's API.

// the analytics edge

Where I think I add something different to most graduates is in the analytics side. One of my modules involved working from raw user log data (clicks, drop-offs, time on page) and translating that into evidence-backed usability recommendations for a real client brief. I genuinely enjoy that part of the work: turning data into something a team can actually act on.

// where I'm headed

I'm also comfortable using AI as a real part of my design and prototyping workflow. The visuals on my still life project were entirely directed and prompted by me using generative AI tools, and I've been actively learning how to use AI as a creative collaborator. Long term, my dream is to grow into a senior UX role where I can shape AI-powered product experiences end to end. For now, I'm looking for a graduate or junior UX position where I can keep learning, contribute meaningful work from day one, and build my skills in a multidisciplinary team.
